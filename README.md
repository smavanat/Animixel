# Animixel: A Rigged Animation Toll for Pixel Art  

## Building and Running:  
This tool requires [CMake](https://cmake.org/) (min version 3.10) as well as a C compiler ([GCC](https://gcc.gnu.org/), [Clang](https://clang.llvm.org/) or [MSVC](https://visualstudio.microsoft.com/vs/features/cplusplus/))  

### Windows  
```
cd ${PROJECT-ROOT}  
mkdir build
cd build
cmake -G "${YOUR-CMAKE-BUILD-CONFIG}" ..
cmake --build .
.\amxl.exe
```

### Mac and Linux  
```
cd ${PROJECT-ROOT}  
mkdir build
cd build
cmake ..
make
./amxl
```

Documentation can be generated by running Doxygen:
```
cd ${PROJECT-ROOT}  
doxygen Doxyfile
```
The output will be placed in the docs directory
A pre-compiled pdf of the current documentation can be found in [docs/pdf](docs/pdf)

  
This project makes use of [GLFW](https://www.glfw.org/), [stb_image](https://github.com/nothings/stb/tree/master), [BOB](https://github.com/smavanat/BOB), [Clay](https://github.com/nicbarker/clay) and [Doxygen](https://www.doxygen.nl/index.html)
