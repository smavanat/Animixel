============================================ FEATURE LIST ==========================================
# Basic features
- Ability to draw the sprite in editor
- Ability to load sprites into the editor

# Animation Editor
- Support basic sprite operations: rotation, stretching/scaling, shearing
- Allow use of bones for sprite animation/deformation
- Allow the use of bones to make transitional animations such as rotations or deformations (like smart bones from Moho)
- Masking out certain sections for animations
- Pixel art specific animation techniques: Subpixel animation
- IK Support

# Data Export
- Allow saving animation frames to a spritesheet
- Allow export of bone and animation data alongside original sprite images
- Create API for parsing this data
- Integrate this API into at least one existing game engine (Godot since it is open source) to demonstrate how it would work

# Extra Features:
- Support common pixel art effects such as blurs, explosions etc
- Support adding skins to rigs
- Animation and effects using Bezier curves/easing functions: 
    https://blog.febucci.com/2018/08/easing-functions/
    https://easings.net/
- Create particle engine for adding effects for animations
- Allow use of shaders to enhance produced animations
