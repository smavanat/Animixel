void canvas_init ( Canvas * c,
size_t width,
size_t height,
size_t scale,
uint32_t default_colour,
BOB_Renderer_Handle r )

Initialises a Canvas.

Does not allocate memory for the struct itself (this must be done beforehand using either a local struct variable or a heap allocation), but will allocate memory for the pixels buffer and will create the PixelBuffer via a call to BOB

Parameters
ca pointer to a Canvas to be initialised
widththe desired width of the Canvas
heightthe desired height of the Canvas
scalethe desired scale factor of the Canvas
default_colourthe background colour the Canvas should default to when first drawn
rthe handle of the BOB_Renderer the Canvas should use to generate its pixelbuffer
